# Planning

Questa cartella contiene i piani di implementazione tecnica delle user story, generati con `/archetipo-plan`.

- Un file per story, con nome `US-XXX-plan.md` (es. `US-001-plan.md`)
- Le user story corrispondenti vivono in [docs/backlog/](../backlog/) con nome `US-XXX-<slug-titolo>.md`
- Quando un piano viene creato, lo stato della story passa a `PLANNED` nell'indice [docs/BACKLOG.md](../BACKLOG.md) e nel campo **Status** del file della story
- I piani vengono poi eseguiti con `/archetipo-implement US-XXX`
